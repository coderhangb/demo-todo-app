# Demo To-Do App ✅

## About
This is a simple **To-Do List web app** built to practice **JavaScript**, **DOM manipulation**, and **local storage**.  
Users can add, edit, delete, and mark tasks as completed directly on the browser — no backend required.

## Features
- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ✅ Mark tasks as completed  
- ❌ Delete tasks  
- 💾 Save tasks in **LocalStorage**
- 🧼 Clear all completed tasks  
- 🎨 Simple and responsive UI  

## Tech Stack
- HTML / CSS / JavaScript  
- LocalStorage for saving data
